# 🎵 MoodMuse

MoodMuse is a Python-based mood music recommendation system that suggests songs based on the user's mood.

## Features

- Personalized user greeting
- Mood-based song recommendations
- Random song selection
- Multiple mood categories

## Technologies Used

- Python

## How to Run

1. Download the repository
2. Run:

python moodmuse.py
