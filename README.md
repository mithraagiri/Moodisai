# 🎵 MoodMuse

A Python-based mood music recommendation system that suggests songs based on the user's current mood.

# 📌 About the Project

MoodMuse is a beginner-friendly Python project created to explore programming concepts by building a practical application.

The program asks the user about their mood and recommends a suitable song from a curated collection of songs.

# ✨ Features

- 👤 Personalized greeting using the user's name
- 😊 Mood-based song recommendations
- 🎵 Random song selection
- 🔄 Continuous interaction until the user exits
- 📚 Organized song library using Python dictionaries
- ⚙️ Function-based program structure

# 🎭 Available Moods

- Happy 😀
- Sad 😢
- Energetic ⚡
- Romantic ❤️
- Motivational ☀️

# 🚀 How to Run

1. Clone this repository:

```
git clone https://github.com/mithraagiri/MoodMuse.git
```

2. Navigate to the project folder:

```
cd MoodMuse
```

3. Run the Python file:

```
python moodmuse.py
```
